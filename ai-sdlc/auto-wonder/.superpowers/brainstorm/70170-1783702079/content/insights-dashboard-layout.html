设计要点

  • 路由: /insights → InsightsPage
  • 两个 Tab: 指标概览 (上图) + 执行审计 (Table)
  • 筛选器: Worker 下拉 + 时间范围 Segmented (7d/30d/90d)
  • 四维指标卡: 成本(黄) / 效率(蓝) / 稳定(绿) / 安全(红) + SVG Sparkline
  • AI 洞察区: 总结卡 + 关键洞察 + SDLC链路问题 + 建议动作
  • 颜色方案: 延续项目整体 #ff6a00 橙色 + 白色背景
