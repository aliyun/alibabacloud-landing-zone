# 记忆审核与清理

日常记忆列表（包括按员工分组）未指定状态时只展示待审、已采纳记忆。显式筛选 REJECTED 可查历史拒绝记录；检索复用仍只允许 ADOPTED。

审核处置规则：

- 原文的关键断言有证据且值得复用：采纳。
- 只有部分断言成立：缩减或修正正文，并在同一 review 请求中采纳。`editedContentMd` 和可选 `editedType` 与 ADOPT 事务提交；普通编辑不会自动变成事实审核。
- 明确错误、过时、已被替代的重复内容或无复用价值：软删除。删除事务清理该空间的员工绑定并保留 DELETE 审计，历史执行包不回写。
- 暂无证据、属于另一系统：保留待审，逐 ID 写明证据缺口、事实来源、恢复条件和接手对象，不能把缺证据等同于错误。

不能以 Terraform 仓库使用 gomonkey 推导其在某环境必然失败，也不能以测试读取环境变量推导 ACC 未注入变量。部分证据只能采纳经缩减后的事实。

SDLC 10019 / 员工 10040 已通过 MCP 更新：冻结范围后处理，每个 ID 只有一个结果，总数和 ID 对齐；收尾复用证据，按当前 attempt 提交 checklist、handoff 和 completion。线上配置变更前后快照保存在本机诊断目录 `16888/policy-update`。

兼容部署：新平台部署前，旧 delete_memory 仍可能拒绝有员工绑定的记忆；SDLC 会退役该条目并明确报告待清理绑定，不会谎称删除成功。历史 39 条待审不会因配置发布自动删除。
