# 证据等级标准

## 三档

### [实证]
有日志/行为/实物/数据佐证,可复核。
- 具体的 seq 或时间戳
- 具体的命令内容
- agent 的原话(从 message/thinking 事件重组)
- 文件的实际存在(ls/stat)

### [现象实证·根因推断]
现象有数据支撑,但根因只读代码推断(未经运行时验证)。
- 需标注"未经运行时验证"
- 不当定案用,只作参考

### [零当前影响]
缺陷成立但本轮未造成任何可观测后果。
- 不报为紧急问题
- 记录为潜在隐患
- 说明什么条件下会变成真问题

## 规则

1. 问题归类和优先级**只基于实证**
2. 推断性结论**必须标注**
3. "可能有问题"**不进报告** — 要么有证据要么不提
4. 修复优先级按"是否已造成真实后果"排,不按理论严重程度
5. **结论终审** — 报告定稿前,每条问题/结论必须挨个回日志复核成立后才能保留;复核发现证据不成立或被反例推翻的,降级为[现象实证·根因推断]或直接剔除
